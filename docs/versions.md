| **v1.0** | `/`（根路径下的所有页面） | Cordelia Morrow 网站结构 + 6 步定制流程。对应提交 `a2f8ca3`（GitHub 上可手动建 tag `v1.0` 指向它）。**保持不动。** |

- v1.1 暂只有浅色主题。

## v1.1 待你确认

1. 品牌名按设计稿用 **Pipixel**（v1.0 是 Cordelia Morrow）。
2. 尺寸按设计稿 29 / 44 / 58；价格是占位。
3. 首页图片目前是从设计稿截图裁出来的（清晰度有限，柯基照片和图纸被清单卡片挡住的部分无法还原）。请提供设计稿里这几张图的**原始 PNG**：柯基照片、柯基拼豆图、橘猫团团、招财进宝、早安咖啡。
5. 熨烫效果是示意画法；如果你有四种熨烫的实拍图，可以换成实拍样图。
4. 设计稿只有首页：其他页面（流程、登录等）是我按首页风格套的，有设计稿后再对齐。
