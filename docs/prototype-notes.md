# 原型说明（里程碑 0）

按你的要求，这一版是**可点击的产品原型**：页面和交互都做了，但"图纸生成"等核心功能暂时用示例数据，没有做真实实现。页面顶部有一条 "Prototype" 提示条，假功能旁边有虚线 **PROTOTYPE** 标签。

> 注意：`CLAUDE.md` 原来要求里程碑 0 的图纸生成必须是真的。这一版按你最新的指示先不做，放到里程碑 1。

## 怎么试

- 部署到 Vercel 后用手机 / 平板打开（步骤见 README）。
- 推荐路径：首页 → Make my pattern → **Use a sample photo**（或上传自己的照片）→ 裁剪 → 调参数 → Generate → 在线拼 → 灯箱 → Get the kit → 购物车 → 结账成功。
- 后台：页脚 **Admin**，任意密码登录。

## 色卡调研结论

没有厂商公开 RGB 值，行业通用做法是用社区从实物豆子上取色的数据。这里收了三套（都允许商用，需要署名）：

| 色卡 | 色数 | 定位 |
|---|---|---|
| **Perler Midi 5mm**（默认） | 103 | 北美零售最主流（Walmart / Michaels / Amazon），美国用户最熟悉的色号 |
| Artkal S 5mm | 199 | 色数最全，懂行的玩家和图纸网站常用；另有 2.6mm 的 C 系列 |
| MARD 221 色 | 221 | 国内拼豆 App 和供应链的通用标准，以后做小程序、找国内供应商会用到 |

夜光、闪粉、荧光、珠光、透明豆已经标记出来，自动生成图纸时不使用。所有颜色值都标了 TODO：上线前要用实际供应商的豆子实测校对，并补上单颗重量。

## 需要你决定的

1. **供货品牌**：材料包实际发哪家的豆子？这决定默认色卡、色号印在图纸上的样子、拣货单。（建议：国内采购 MARD 或 Artkal 成本低；如果主打"和 Perler 兼容"，图纸上可以同时显示 Perler 色号）
2. **要不要让用户选色卡品牌**：原型里放了下拉框，方便你比较三套色卡的效果。正式版也可以去掉，固定用我们自己的品牌色卡。
3. **2.6mm 色卡**：目前 2.6mm 和 5mm 共用一套色卡，要等确认 2.6mm 的供应商。
4. **价格**：三档 $24 / $39 / $59 都是占位。
5. **尺寸档位**：按长边算 29 / 52 / 78 格，长方形照片的短边按比例算。这样可以吗？
6. **在线拼的交互**：现在点格子是"放豆 / 取消"切换；没选颜色时点格子会自动选中那个颜色。要不要支持手指划过连续放豆？
7. **灯箱**：点亮的孔用该颜色的实色加白圈表示。要不要改成纯白光（透过半透明底板更亮）？
