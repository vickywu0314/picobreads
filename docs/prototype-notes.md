# 原型说明（里程碑 0）

品牌：**Cordelia Morrow**（标语 *Your moments, made personal.*）。网站结构见 [`sitemap.md`](sitemap.md)。

这一版是**可点击的产品原型**。**照片 → 拼豆图纸是真实生成的**（浏览器内 Web Worker 运行，照片不上传）；下单、邮件、魔法链接、后台等仍是假数据，页面上有虚线 **PROTOTYPE** 标签。

图纸引擎（`packages/pattern-engine/src/generate.ts`）有两种生成方式，默认自动判断（设置里可手动选「自动 / 插画 / 照片」）：
- **插画 / 卡通**：先把原图像素归到所选色卡的颜色，再让每颗豆「投票」取主色，深色线条和眼睛加权，轮廓清楚、没有脏的中间色；细节程度 ≤ 3 时再去掉孤立杂点。
- **照片**：每颗豆取面积平均色（线性 RGB），按「细节」柔化 / 锐化，适合皮肤、天空等渐变，可选抖动。
- 两者共用：Lab 空间 k-means 量化 → CIEDE2000 映射到真实色卡 → 合并用量过少的颜色直到不超过上限。
- 尺寸提示：人脸、细线条建议用大号（78 格）。标准号（52 格）每颗豆约代表原图 10×10 像素，比一颗豆还细的线条只能尽量保留。

## 怎么试

- 部署到 Vercel 后用手机 / 平板打开（步骤见 README）。
- 推荐路径：首页 → Create Your Beads（或 拼豆 → 图案库 → 选一个 → Customize This Pattern）→ 6 步定制（上传 → 裁剪 → 规格 → 预览 → 购买形式 → 确认）→ 购物袋 → 结账 → 我的账户。
- 账户：任意邮箱 + 任意 6 位验证码即可「登录」（原型）。后台：页脚「原型工具 · Admin」，任意密码。

## 色卡调研结论

没有厂商公开 RGB 值，行业通用做法是用社区从实物豆子上取色的数据。这里收了四套（都允许商用，需要署名），用户在「调整图纸」页选择：

| 色卡 | 色数 | 定位 |
|---|---|---|
| **Perler Midi 5mm**（默认、推荐） | 103 | 北美最知名，各方评价里品质最稳定（尺寸、颜色、熔烫一致） |
| Artkal S 5mm | 199 | 色数最全，适合人像和细腻过渡；另有 2.6mm 的 C 系列 |
| Hama Midi 5mm | 92 | 丹麦老牌，欧洲主流，品质可靠 |
| MARD 221 色 | 221 | 国内拼豆 App 和供应链的通用标准，性价比高 |

材料包质量优先，所以默认推荐 Perler。

**已定（方案一）**：材料包只卖 **Perler 和 Artkal** 两家；Hama、MARD 只用于免费图纸和在线拼，品牌卡片上标「暂只提供图纸」。用这两家生成的图纸去买材料包时，会提示一键改用 Perler / Artkal 色卡重新配色。可售品牌在 `apps/web/src/config/site.ts` 的 `KIT_PALETTE_IDS` 配置，后台「配置」页也有对应开关（原型不保存）。注意：网上没有严格的横向评测，以上是综合多个爱好者 / 卖家来源的共识，建议采购前每家买一小包实际熨烫对比。

夜光、闪粉、荧光、珠光、透明豆已经标记出来，自动生成图纸时不使用。所有颜色值都标了 TODO：上线前要用实际供应商的豆子实测校对，并补上单颗重量。
