# BeadSpark 微信小程序

原生小程序 + TypeScript。图纸引擎和网站是同一份（`packages/pattern-engine`，打包成 `miniprogram/lib/engine.js`），
账号、草稿、分享用同一个后端（`apps/api`）。

## 功能（第一版）

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `pages/index` | 上传照片（相册 / 拍照）→ 选比例（1:1 / 3:4 / 4:3）裁剪 → 进入定制；「继续上次的作品」 |
| 定制 | `pages/create` | 迷你豆 / 标准豆、去掉背景、裁掉空白边；四张效果图（1 / 4 / 9 块底板 + 像素风），自动推荐并预选（和网站同一套规则）；大图预览（完成后 / 你的照片）；开始在线拼、存草稿。照片只在手机上处理 |
| 购买形式 | `pages/product` | 定制页点「下一步」进入：免费下载图纸 / 购买材料包 / 直接购买成品（后两个蒙灰「即将开放」）；你的图纸（尺寸、成品大小、底板、颜色颗数）、材料清单；「保存图纸到相册」（一张图：带编号的彩色格子 + 材料清单）、「先在线拼拼看」 |
| 在线拼 | `pages/bead` | 立体钉板；下面选颜色，在板上点或划放豆（手指要靠近格子中间才放，不会窜行）；「放豆 / 移动」切换，双指缩放，＋ − 全图；撤销；进度；拼完进入完成页；购买、分享 |
| 拼完 | `pages/done` | 最后一颗放好后进入：作品图，「购买拼好的成品」（即将开放）→「分享给朋友」→「先不了」 |
| 我的 | `pages/mine` | 打开小程序自动微信登录、改昵称、退出；**放过豆的图自动存到账号**（不用点保存），分「拼好的」「拼到一半的」两组（继续拼 / 查看 / 买成品 / 分享 / 删除）。和网站同一个账号体系 |
| 分享 | `pages/share` | 作品图、作者、浏览数、尺寸颜色颗数、用豆清单；「照着拼一个」「用我的照片做一个」。自己分享时：发给微信好友 / 群（分享卡片）、保存分享海报（带小程序码）；右上角「···」可分享到朋友圈 |

## 在开发者工具里打开

1. 微信开发者工具 → 导入项目 → 目录选仓库里的 **`apps/miniprogram`**（不是 `miniprogram` 子目录）。
2. AppID 已经写在 `project.config.json` 里（`wxad095cfa10de6ecd`）。
3. 本机测试连后端：
   - `miniprogram/utils/config.ts` 里 `API_BASE` 按版本自动选：开发版（开发者工具 / 预览 / 真机调试）连 `http://49.233.85.32`，体验版和正式版连 `https://pd.scentby.cn`。所以**上传体验版 / 提审前，https 域名必须已经通了**。
   - `project.private.config.json` 已经设了「不校验合法域名」，开发者工具和真机预览（打开调试）里可以连 http 的 IP。**正式上传 / 体验版必须用 https 域名**。
4. 服务器上要填小程序的 AppID 和 AppSecret（见下面「服务器」），否则「微信登录」会提示「服务器还没配置小程序登录」。

## 改了代码之后：重新编译

小程序直接运行的是 `.js`。源码是旁边的 `.ts`，`.js` 由编译脚本生成并一起提交（这样开发者工具打开就能用，不依赖它的 TypeScript 编译设置）。
改了 `miniprogram/` 里的 `.ts`，或者改了图纸引擎（`packages/pattern-engine`）之后，运行：

```bash
pnpm --filter miniprogram build
```

它会重新生成 `miniprogram/lib/engine.js` 和每个 `.ts` 对应的 `.js`。上传时 `.ts` 文件会被忽略。

## 上线前要在小程序后台配置

1. **服务器域名**（开发管理 → 开发设置 → 服务器域名）：
   - request 合法域名：`https://pd.scentby.cn`
   - downloadFile 合法域名：`https://pd.scentby.cn`（分享海报上的小程序码）
2. **用户隐私保护指引**（设置 → 服务内容声明 → 用户隐私保护指引）：声明用到了「选中的照片或视频」（选照片）和「相册（仅写入）」（保存海报）。不填的话这两个功能会被微信拦掉。
3. **服务类目**：选「工具 > 图片 / 设计」之类与拼豆图纸相符的类目。
4. 分享到朋友圈：小程序要已发布（或体验版），且页面实现了 `onShareTimeline`（分享页已实现）。朋友圈打开是「单页模式」，只能看作品，点「照着拼」等需要先「前往小程序」。

## 服务器（后端）

最省事：登录服务器运行 `sudo bash ~/beadspark-deploy/set-wxmp.sh`，按提示填 AppSecret。手动的话，在服务器的 `/etc/beadspark/api.env` 里填（小程序后台 → 开发管理 → 开发设置）：

```
WXMP_APP_ID=你的 AppID
WXMP_APP_SECRET=你的 AppSecret
WXMP_ENV=release      # 体验阶段想让海报上的码打开体验版，改成 trial
```

然后 `sudo systemctl restart beadspark-api`。同一个微信用户在小程序和网站微信登录是同一个账号（需要小程序和网站应用绑在同一个微信开放平台账号下，才有 unionid）。

## 购买（材料包 / 成品）和微信支付

- 入口：购买形式页（定制后「下一步」）、在线拼顶部「购买」、拼完页「购买拼好的成品」、「我的」里每个作品的「买材料包 / 买成品」。拼到一半的也可以买。
- 流程：选形式 → 选收货地址（微信地址簿）→ 微信支付 → 服务器向微信确认到账 → 「我的 → 我的订单」。付款成功后新订单会发邮件到 `ADMIN_EMAIL`（收货信息 + 图纸链接）。
- 价格按图纸大小分三档（1 个分区 / 2～4 个分区 / 更多），在服务器上配置；某种形式的三档价格和商户资料都填好才开卖，否则显示「即将开放」。
- 开通：服务器上运行 `sudo bash ~/beadspark-deploy/set-shop.sh`（商户号、APIv3 密钥、证书序列号、私钥文件、价格、通知邮箱）。前提：微信支付商户号已开通并关联这个小程序的 AppID；支付通知地址必须是 https 域名。
- 小程序后台「用户隐私保护指引」要加上「收货地址」。
- 订单详情页 `pages/order`：状态、商品、收货信息、订单号；未付款可「继续支付」「取消订单」（110 分钟不付自动取消）；发货后显示快递公司和运单号（可复制）；联系客服。
- 订单管理后台（网站 `/admin/`，口令 = 服务器 `ADMIN_TOKEN`，`set-shop.sh` 会生成并显示）：待发货 / 已发货 / 已退款 / 待付款列表，订单里有图纸、收货信息、拣货清单（材料包多备 10%，按 500 / 100 / 50 颗的袋子凑），填快递单号标记发货，全额退款（走微信原路退回）。
- 还没有：部分退款、发货后的微信通知（需要申请订阅消息模板）、物流轨迹查询。
